<section class="cn-sec is-key" data-cat="care">
  <div class="cn-sec-head">
    <span class="cn-sec-no">01</span>
    <h2 class="cn-h">지원 내용</h2>
    <span class="cn-sec-tag">금액이 적힌 항목</span>
  </div>
  <div class="cn-sec-body">
<div class="cn cn-raw" data-cat="care">
<p>2026년 0세에서 5세 아동의 지원단가(보육사업안내26년 책자 297페이지)</p>
<p>ㅇ 0세반 : (기본보육) 584,000원 / (야간) 584,000원 / (24시) 876,000원</p>
<p>ㅇ 1세반 : (기본보육) 515,000원 / (야간) 515,000원 / (24시) 772,500원</p>
<p>ㅇ 2세반 : (기본보육) 426,000원 / (야간) 426,000원 / (24시) 639,000원</p>
<p>ㅇ 3~5세반 : (기본보육) 280,000원 / (야간) 280,000원 / (24시) 420,000원</p>
<p>지자체에 보육료 지원을 신청한 날 부터 지원합니다.</p>
<ul>
  <li>보육료 신청보다 어린이집에 먼저 입소한 경우 보육료 신청일 기준으로 지원합니다.</li>
  <li>단, 양육수당에서 보육로로 변경 신청한 경우에는 당월 15일 이전에 신청하면 변경신청일부터 보육료 지원 자격 부여하고, 당월 16일 이후에 신청하면 익월 1일 부터 보육료 지원 자격을 부여합니다.</li>
  <li>보육서비스(보육료, 양육수당, 유아학비, 아이돌봄)간 변경 기준이 상이하므로 상세한 사항은 교육부 02-6222-6060 또는 지자체에 문의</li>
</ul>
<p>어린이집 입소 여부와 별도로 입소일 전일 또는 입소와 동시에 보호자의 보육료 지원 자격 신청이 필요합니다.</p>
<ul>
  <li>(입소일 이후 신청) 신청일부터 보육료 지원(보호자의 보육료 자부담 발생 가능)</li>
  <li>(입소일=신청일) 입소일 - 신청일부터 보육료 지원</li>
  <li>(입소일 이전신청) 입소일 부터 보육료 지원</li>
</ul>
</div>
  </div>
</section>

<section class="cn-sec" data-cat="care">
  <div class="cn-sec-head">
    <span class="cn-sec-no">02</span>
    <h2 class="cn-h">어떻게 신청하나요?</h2>
    <span class="cn-sec-tag is-prose">본 사이트가 쓴 문장</span>
  </div>
  <div class="cn-sec-body">
<div class="cn cn-steps" data-cat="care">
  <div class="cn-step">
    <span class="cn-step-no">1</span>
    <div class="cn-step-body">
      <h4>온라인 신청</h4>
      <p>온라인 신청은 지정된 웹사이트에서 신청서를 작성하고 필요한 서류를 전자파일 형태로 첨부하면 됩니다. 신청일을 기준으로 보육료 지원이 시작됩니다.</p>
    </div>
  </div>
  <div class="cn-step">
    <span class="cn-step-no">2</span>
    <div class="cn-step-body">
      <h4>방문 신청</h4>
      <p>방문 신청은 관할 지자체 보육 담당 부서에 직접 방문하여 서류를 제출하면 됩니다. 입소일 이전에 신청하면 입소일부터, 입소일과 동일하면 입소일부터, 입소일 이후에 신청하면 신청일부터 지원됩니다.</p>
    </div>
  </div>
</div>
<h4 class="cn-sub">준비 서류·서식</h4>
<ul class="cn cn-check" data-cat="care">
  <li>ㅇ 신청인 제출서류</li>
  <li>사회복지서비스 및 급여제공(변경) 신청서</li>
  <li>사회복지서비스 이용권(바우처) 제공(변경) 신청서</li>
  <li>아이사랑 카드 발급 신청 및 개인신용정보의 조회</li>
  <li>제공</li>
  <li>이용 동의서</li>
</ul>
  </div>
</section>
